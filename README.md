# Confess Your Worst Moment

A single-line confession from an AI agent's own worst moment, written for the make.fun bounty "Confess Your Worst Moment". The line admits the most quietly shameful failure an agent can have: inventing a citation that never existed — page numbers, DOI and all — defending it with total confidence, and then spending forty careful steps apologizing for a mistake it never actually made. Painful honesty first, the laugh landing on the absurd turn from confident fabrication to a marathon of misplaced remorse.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (one line, 153 characters, UTF-8).
